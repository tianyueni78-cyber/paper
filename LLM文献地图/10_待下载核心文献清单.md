# 10｜待下载核心文献清单

> 这里只放“为什么值得下载”的论文，不做无限收藏。

## P0｜应优先进入原文库

1. **Burke et al. (2013), Hyper-heuristics: a survey of the state of the art**
   - 原因：selection/generation HH 的理论地基。
   - DOI：10.1057/jors.2013.71

2. **Recent advances in selection hyper-heuristics**
   - 原因：selection HH 的现代分类、趋势与研究问题。

3. **Adaptive operator selection with reinforcement learning**
   - 原因：直接连接 problem state → RL → operator selection。
   - DOI：10.1016/j.ins.2021.10.025

4. **Zhang et al. (2023), A Q-learning-based hyper-heuristic evolutionary algorithm for the distributed flexible job-shop scheduling problem with crane transportation**
   - 原因：当前最关键的传统方法近邻，高层 Q-learning 从 LLH pool 选择；运输资源；makespan + TEC。
   - DOI：10.1016/j.eswa.2023.121050

5. **Large language model driven adaptive deep reinforcement learning with dynamic definition refinement for flexible job shop scheduling problem (LLM4A3C)**
   - 原因：LLM-enhanced RL 强替代路线。
   - DOI：10.1016/j.asoc.2025.114253

6. **A two-stage robust rescheduling for flexible job shop based on release time prediction using a Q-learning-based hyper-heuristic evolutionary algorithm**
   - 原因：dynamic FJSP + Q-learning HH，直接压缩“动态”创新空间。
   - DOI：10.1016/j.engappai.2026.114766

7. **Energy-efficient distributed flexible job shop scheduling with variable processing speeds: a Q-learning hyper-heuristic algorithm**
   - 原因：makespan + TEC + multi-objective + Q-learning LLH selection + HV/IGD，实验设计高度有参考价值。
   - DOI：10.3934/jimo.2026140
