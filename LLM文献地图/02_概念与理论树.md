# 02｜概念与理论树

> 原则：不自造术语。术语若尚未确认已有稳定学术用法，标为“工作描述”，不冒充正式概念。

# A｜基础概念

## Flexible Job Shop Scheduling Problem（FJSP）
柔性作业车间调度：每道工序可由一组候选机器中的某台加工，需要同时决定工序排序和机器分配。

**本课题作用**：基础调度问题。

## Dynamic FJSP（DFJSP）
在静态 FJSP 基础上考虑生产过程中的动态事件，例如新任务到达、机器故障等，并进行动态决策或重调度。

**注意**：dynamic scheduling、rescheduling、reactive scheduling、predictive-reactive scheduling 不应混为同义词，后续写作必须按具体文献定义使用。

## Machine–AGV Integrated Scheduling
机器加工与 AGV 运输决策耦合的调度问题。

**本课题作用**：运输不是外生常数，而是与机器加工共同影响可行性、完工时间与能耗。

## Multi-objective Optimization
同时优化多个相互冲突目标。本课题当前为 Makespan 与 TEC。

## Pareto Dominance / Pareto Front
用于多目标优化解集评价与选择的基础概念。

# B｜方法概念

## Metaheuristic
面向复杂搜索问题的高层搜索框架，例如 evolutionary algorithms、local search 等。

## NSGA-II
经典多目标进化算法。本课题当前作为底层优化主框架，而不是 LLM 的替代对象。

## Hyper-Heuristic（HH）
【已核验定义来源】Burke et al. (2013) 将 hyper-heuristic 概括为用于**选择或生成 heuristics** 的搜索方法或学习机制；其关键区别是搜索作用于 heuristic / heuristic components 空间，而非直接作用于原问题解空间。

### Selection Hyper-Heuristic
从已有低层 heuristics 中选择当前要使用的 heuristic。

**与本课题关系：极高。**

### Generation Hyper-Heuristic
生成新的 heuristic 或 heuristic component。

**与本课题区别**：EoH、LLaMEA 等 LLM-AHD 工作主要更接近这一侧，而当前候选方案主要是“选择固定策略库”。

## Low-Level Heuristic（LLH）
由高层 hyper-heuristic 选择或控制的底层 heuristic/operator。

## Adaptive Operator Selection（AOS）
根据搜索过程中的信息动态选择 operator。

【已核验证据】2021 年 Information Sciences 的 “Adaptive operator selection with reinforcement learning” 明确研究利用 problem state 进行 RL-based operator selection，并强调 operator sequence 与互补性会影响搜索表现。

**与本课题关系：理论近邻，需要继续系统补齐经典 AOS 文献。**

## Algorithm Selection
根据问题/实例特征从候选算法中选择合适算法的研究传统。

**与本课题关系**：提供“context → choice”的更上层理论祖先，但粒度通常是算法/solver，而本课题更细到策略/operator。

## Reinforcement Learning（RL）
通过 state、action、reward 与环境交互学习策略。

## Q-learning
model-free value-based RL 方法。

**本课题作用**：原高层 selector，也是 LLM selector 的核心竞争基线。

【已核验证据】Zhang et al. (2023) 在带 crane transportation 的 distributed FJSP 中使用 Q-learning high-level strategy，从预设计 LLH 集合中选择策略，并使用 LLH efficacy 信息构造高层控制。

# C｜前沿概念

## Automated Heuristic Design（AHD）
自动设计 heuristic 的研究方向。LLM 出现后形成 LLM-based AHD / LLM-driven heuristic design 等研究路线。

## LLM-Driven Heuristic Design（LHD）
DASH 等近期论文采用的表述，典型流程为：

`LLM generate/refine solver → execution → evaluation → selection → further refinement`

## Language Hyper-Heuristic
部分近期论文用于描述 LLM 作为 heuristic evolution / design engine 的方向。

**注意**：该词目前不能自动等价于“LLM selection hyper-heuristic”。

## Structured State Abstraction（SSA）
TPET 中的具体模块名称：把高维数值交通状态与历史转换为结构化 temporal-logical facts，供策略生成/执行使用。

**本课题可借鉴机制**：raw scheduling/search state 不应未经筛选直接塞入 LLM。

## Dynamics-Aware Solver Adaptation
DASH 所体现的路线：不仅看最终 endpoint performance，也利用 convergence trajectory、runtime schedule 和 instance profile。

**本课题可借鉴机制**：搜索阶段、停滞、预算、历史改善可能属于有效上下文。

## Multi-Operator Co-design
E2OC 研究多个相互依赖 operator 的联合设计和 coupling，而不是单个 operator 独立演化。

**与本课题区别**：co-design ≠ online selection。

# D｜相邻但不能混淆的概念

| 概念 | 它解决什么 | 与本课题的区别 |
|---|---|---|
| LLM mathematical modeling | NL → 数学模型/solver code | 本课题已有优化模型，不以自动建模为核心 |
| LLM heuristic generation | 生成新的 heuristic/code | 本课题当前优先选择已有策略 |
| Multi-operator co-design | 联合设计多个 operator | 本课题关注运行中的选择 |
| Algorithm selection | 实例 → 选择完整算法/solver | 本课题粒度更细 |
| Parameter control | 动态调整参数 | 策略选择不等于连续/离散参数控制 |
| Online LLM actor | LLM 每个环境 step 直接决定动作 | 本课题候选方案是高层搜索控制，不直接排每道工序 |
| LLM-enhanced RL | LLM 改 state/reward/policy learning | 本课题候选方案是替代 Q-learning selector，必须与增强 RL 路线竞争 |
