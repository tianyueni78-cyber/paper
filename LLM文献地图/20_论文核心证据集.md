# D｜Direct Competitors / Boundary Killers

## D1｜HeurAgenix（23）

**资格：T1｜必引**

承担的 claim：

> LLM 已经可以根据 current problem state，从 heuristic pool 中进行在线 heuristic selection。

它直接否定：

> “LLM 从 heuristic pool 在线选择 heuristic”本身是创新。

当前研究必须把差异落到：

- 动态调度环境状态；
- search-process state；
- Pareto state；
- 显式 strategy-effect history；
- remaining real-evaluation budget；
- 与 Q-learning 做同模块同预算替换。

## D2｜ReflecSched（19）

**资格：T1｜必引**

承担的 claim：

> LLM 已经进入 dynamic FJSP，并能通过 hierarchical reflection / strategic experience 支持即时调度决策。

它直接否定：

> “LLM 尚未进入 dynamic FJSP / dynamic scheduling”。

## D3｜LLM Wireless Power Control（58）

**资格：T1｜必引**

承担的 claim：

> LLM 已经可以读取 current state 与 `(state, action, reward)` experience history 进行在线决策。

它直接否定：

> “history-aware online LLM decision”本身是创新。

## D4｜TPET（09）

**资格：T1｜必引**

承担的 claim：

> 高频 online LLM actor 的 latency/cost 可能不合理，LLM 更适合作为较慢的 policy discovery / supervisory layer。

它是当前架构必须面对的反向证据，不是“支持我们用 LLM”的装饰引用。
