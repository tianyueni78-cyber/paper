# 已被直接杀死的宽泛创新表述

以下表述当前禁止使用：

1. “首次用 LLM 生成 heuristic。”
2. “首次让 LLM 从 heuristic pool 选择策略。”
3. “首次让 LLM 根据当前状态在线决策。”
4. “首次让 LLM 利用历史 reward 决策。”
5. “首次把 LLM 用到 dynamic FJSP。”
6. “首次进行 LLM + multi-objective optimization。”
7. “首次让 LLM 感知搜索过程。”
8. “首次用反馈改进 LLM optimization。”
9. “LLM 比 Q-learning 更智能，因此应替代 Q-learning。”

这些要么已有直接证据，要么逻辑上不是可验证 novelty claim。

# Surviving Candidate Gap

当前仍可能成立，但必须继续接受新文献攻击的候选机制：

## G1｜Environment-state + Search-process-state 联合 supervisory selection

候选差异不是“有 state”，而是同一 selector 同时读取：

- dynamic event / machine / AGV bottleneck；
- search stage；
- Pareto stagnation / diversity；
- previous strategy effect；
- strategy trajectory；
- remaining real-evaluation budget。

**状态：SURVIVING / 待直接竞品检索。**

## G2｜Pareto-aware strategy-effect credit

不是“做多目标”，而是把策略效果描述为对 Pareto front / HV / diversity 的实际贡献，而非单一人工 scalar reward。

**状态：SURVIVING / 中等置信。**

## G3｜Delayed / trajectory-level strategy credit

不是简单把 reward history 塞进 prompt，而是识别：某策略可能短期无改善、长期打开新区域；如何把后续收益归因给先前高层动作？

**状态：SURVIVING / 中等置信。**

## G4｜同模块、同真实解码预算的 LLM vs Q-learning selector 因果比较

保持：

- strategy library 相同；
- optimizer 相同；
- decoder 相同；
- dynamic events 相同；
- real evaluations 相同；
- 只替换 selector。

其价值未必是“算法机制首次出现”，但可能构成**可信实验贡献与能力边界贡献**。

**状态：SURVIVING / 高可执行性。**

## G5｜质量收益 vs 推理成本/延迟的 break-even boundary

在线 LLM 是否值得，不应只看 HV。需要回答什么场景、什么调用频率、什么动态事件强度下收益覆盖推理成本。

**状态：SURVIVING / 高现实价值。**

# 当前最稳妥的定位

> 当前研究不能以“LLM selector”作为创新，而应把论文问题收窄为：在固定低层优化器与策略库中，**联合环境状态与搜索过程状态的 LLM supervisory selector 是否能在同预算条件下产生可复现的质量、适应性或泛化增益；若能，这种增益来自哪些信息与反馈机制，并是否足以覆盖推理成本。**

这仍是候选研究定位，不是最终 novelty 声明。
