# LLM 文献地图

> 目的：建立与 `LLM/` 原文库隔离、可持续维护的研究型文献体系。这里保存“研究地图与判断”，`LLM/` 继续保存论文转换原文。两者不与 `paper-explaination` 交叉。

## 当前研究锚点

研究对象：动态多目标 FJSP-AGV（柔性作业车间 + AGV 协同）。

候选机制：**结构化动态上下文 → 高层策略选择器 → 固定策略/算子库 → 原优化器执行 → 性能反馈**。

当前核心研究问题：

> 在不直接修改底层优化器的前提下，能否让 LLM 利用动态调度事件、搜索过程状态与历史策略反馈，从预定义策略/算子库中进行上下文感知选择，并在相同求解预算下达到或超过 Q-learning 高层选择器？

这只是当前研究假设，不是已验证结论。

## 与原文库的关系

- `LLM/`：论文原文转换文本，作为证据源。
- `LLM文献地图/`：对论文进行定位、比较、证据分级和研究判断。
- `paper-explaination`：不作为本体系的写入目标，避免当前研究路线变化造成交叉污染。

## 文献距离等级

- **S｜直接竞争者**：研究问题和机制高度相似，必须正面对比。
- **A｜直接支撑**：直接支撑本研究某个关键机制，但不等于完成了本研究。
- **B｜间接借鉴**：对象或方法不同，机制可迁移。
- **C｜背景**：只用于建立领域背景或旁支。

## 证据标签

- **【原文事实】**：论文明确写出的内容。
- **【我的归纳】**：基于一篇或多篇文献的结构化归纳。
- **【推测】**：合理但证据不足。
- **【待验证】**：需要继续检索原文或实验验证。

## 新文献准入规则

每篇新论文进入核心库前回答五个问题：

1. 它填三层问题地图中的哪一格？
2. 它是奠基、方法、近邻、前沿还是替代路线？
3. 它比已有核心论文增加了什么新信息？
4. 它是否改变当前研究判断？
5. 它是否值得进入核心阅读列表？

如果没有增加新的理论、机制、证据或竞争关系，只归档，不升级为核心文献。

## 当前最重要的补证方向

1. Selection Hyper-Heuristic / Adaptive Operator Selection 的理论与经典文献。
2. Q-learning / RL 高层 heuristic selector 在 FJSP、动态调度、运输资源协同中的直接文献。
3. LLM 作为已有策略库在线 selector 的直接研究。
4. Dynamic FJSP / FJSP-AGV 中 LLM 与 RL 的直接竞争或混合方法。
5. 公平实验协议：相同真实解码预算、相同策略库、相同底层优化器、LLM 推理成本与延迟如何计入。
