## 重要反例

1. **HeurAgenix** 否定“LLM 在线从 heuristic pool 选策略就是新颖”的宽泛表述。
2. **ReflecSched** 否定“LLM 尚未进入 dynamic FJSP”的宽泛表述。
3. **Wireless Power Control** 否定“LLM 尚未利用 state-action-reward history 在线决策”的宽泛表述。
4. **GraphArena / NLGraph** 否定“LLM 直接推理规模扩大后自然仍有效”的乐观假设。
5. **TPET** 提醒：高频 online LLM 的 latency 可能使离线发现 fast policy 更合理。

# 当前证据的边界

【待验证】本库 69 篇虽然已经覆盖 LLM+Optimization 的主要相邻路线，但不能据此宣称“全世界没有某方法”。尤其是 2025–2026 发展很快，以下直接检索仍应继续：

- LLM online operator selection inside evolutionary search；
- LLM selector vs AOS/RL/Q-learning with identical operator library；
- dynamic FJSP-AGV 中使用 Pareto/search-process state 的 LLM controller；
- latency-aware / asynchronous LLM scheduling control。

因此四张地图是**可修正模型**，不是封死的综述结论。
