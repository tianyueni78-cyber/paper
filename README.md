# 论文与文献原文库

本仓库用于保存研究所依据的论文转换文本，不保存实验代码、研究进度或尚未核验的研究结论。

- 研究对象原文放在[原始论文](原始论文/)。
- 其余Markdown文件为动态调度、机器–AGV协同、强化学习和路径规划相关文献。
- 文献检索、筛选、机制对照与创新性判断放在[paper-explaination](https://github.com/tianyueni78-cyber/paper-explaination)，不与原文混放。

已通过SHA-256核对并删除L025、L026和L031的完全重复导出副本；每篇保留一份原文转换文本。内容存在差异的版本不得仅凭文件名合并。
