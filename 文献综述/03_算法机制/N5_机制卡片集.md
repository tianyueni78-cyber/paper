# N5 机制卡片集

## 1. 卡片口径

- 卡片 ID 与书目 ID 一一对应：`M001↔B001`，不重排。
- `直接`表示机制可由原文摘要、方法章节、算法框图或伪代码定位；`结构化归纳`表示 N5 将分散描述整理成统一调用链，不代表作者使用了该术语。
- 失效条件是“方法依赖的假设不成立时可能失效或需要重构”，不是论文已经实验证明失败。
- `未报告`保持为空缺事实，不按常识补全。

## 3. 加深卡片：关键完整调用链

### M001：QNSGA-II

`事件/静态实例 → OS-MS-AS表示 → 混合初始化 → 电量检查/充电/左移解码 → 目标评价 → NSGA-II选择交叉变异 → 子代解码/评价 → Q-learning选择N1–N6 → 邻域候选解码/评价 → 奖励与Q表更新 → 父子代合并/非支配排序/精英保留 → Pareto调度`

- Q-learning的职责是**选择邻域动作**，不是替代NSGA-II，也不直接输出完整调度。
- 动态模式先由事件专用策略确定哪些变量冻结/重置，再调用同一QNSGA-II求未完成部分。

### M004：HGFN-PPO

`工序—机器—AGV异构图 → 节点/边特征 → 动态注意力融合 → 联合动作掩码 → PPO策略采样 → 环境转移与奖励 → 参数更新 → 调度策略`

- HGFN负责表征，PPO负责策略更新，环境负责可行转移；三者不能合写成一个“新算法模块”。

### M010：DMA-DDQN

`机器/工件/AGV状态 → 多智能体局部观测 → 可行动作 → DDQN估值 → 奖励成形协调 → 联合调度动作 → 环境更新`

- 多智能体结构负责拆分决策主体，DDQN负责动作价值学习，奖励成形负责协调；“DMA-DDQN”不能替代这三项职责说明。

### M016：动态联合调度与组合恢复

`动态到达/工时状态 → DQN从9种工序—机器—AGV复合规则中选一项 → 执行工序/机器/AGV指派 → 时间窗A*路径可行化 → 事件影响识别 → 右移候选/完全重调度候选 → 偏差评价 → 选择恢复方案`

- DQN与时间窗A*的名称及职责可由英文摘要和决策过程定位；网络层数、超参数等内部细节在转换文本中不完整，仍保持未报告。

### M017：析取图MSPPO

`工序—机器—AGV析取图 → 图状态特征 → 加工/车辆/速度/充电动作 → MSPPO策略更新 → 多目标调度`

- 析取图是状态/约束表示，MSPPO是策略学习器，速度和充电是直接动作职责；三者处于不同层。

### M021：路径混合链

`数字孪生状态 → 改进A*初始路径 → DQN局部动态修正 → 冲突检测 → 基线CBS约束分裂或改进CBS车辆优先等待 → 低层改进A*受约束重算 → 无冲突路径 → 孪生反馈`

- 基线CBS高层添加冲突约束；论文提出的改进高层不再沿用同一责任，而是保持高优先AGV路径并让低优先AGV等待，以压缩约束树分支。低层受约束重算仍由改进A*承担。

### M025：排产—分车—路径顺序链

`工件/机器数据 → 改进NSGA-II生成加工顺序 → 竞争机制分配AGV任务 → 改进A*生成路径 → 冲突消解 → 可执行双资源方案`

- NSGA-II不直接寻路，A*不决定工序顺序；顺序链在高拥堵场景可能需要路径结果向上游排产反馈。

### M027：规则选择型D3QN

`事件/完成点 → 8维状态 → MachineRank → 7个复合规则动作 → D3QN估值并选规则 → 工序/机器执行 → AGV运输与环境推进 → 下一决策点`
