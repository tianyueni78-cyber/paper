# N5 方法流程图

## 1. 图例

- 实线箭头：主数据流。
- 虚线语义（文字标注“反馈”）：评价或事件返回上游。
- `待核`：现有转换文本不足，不补造调用细节。

## 2. B001 QNSGA-II 完整调用链

```mermaid
flowchart TD
    A[实例或事件快照] --> B[提取作业/机器/AGV/电池状态]
    B --> C{静态还是动态}
    C -->|静态| D[构造OS-MS-AS三段表示]
    C -->|动态| E[事件专用策略: 取消/机器故障/AGV故障]
    E --> F[冻结已完成与事件相关变量]
    F --> D
    D --> G[混合初始化: 三类问题导向子群]
    G --> H[主动左移解码]
    H --> H1[电量检查]
    H1 --> H2[必要时插入充电]
    H2 --> H3[机器与AGV时间可行插入]
    H3 --> I[计算makespan与TEC]
    I --> J[NSGA-II非支配排序/拥挤距离]
    J --> K[选择/交叉/变异]
    K --> L[Q-learning读取搜索状态]
    L --> M[选择N1-N6邻域动作]
    M --> N[局部搜索与奖励反馈]
    N --> J
    J -->|达到停止条件| O[Pareto解集]
    O --> P[动态方案另计算重调度稳定性]
```

### 职责核对

| 模块 | 负责 | 不负责 |
|---|---|---|
| 事件策略 | 决定保留/释放哪些变量 | 不执行多目标搜索 |
| 三段编码 | 表示工序、机器、AGV选择 | 不生成具体开始时间 |
| 解码器 | 充电、运输和加工时序可行化 | 不选择最优邻域 |
| NSGA-II | 全局多目标演化与精英保留 | 不自动理解事件语义 |
| Q-learning | 根据反馈选择邻域 N1–N6 | 不直接替代染色体或解码器 |

**失效边界：**并发事件、错误状态继承、未建模路径冲突或充电参数偏差会使该调用链需要扩展，而不是仅调节NSGA-II参数。

## 3. 联合进化优化通用链

代表文献：B002、B005、B011、B018、B019、B022、B028。

```mermaid
flowchart LR
    A[联合问题模型] --> B[多段编码]
    B --> C[随机/规则/混合初始化]
    C --> D[解码与约束检查]
    D --> E[目标评价]
    E --> F[GA/FPA/FOA/DE全局更新]
    F --> G{是否含局部强化}
    G -->|VNS/规则/Q学习| H[邻域或策略选择]
    G -->|否| I[选择与档案]
    H --> I
    I -->|继续| D
    I -->|停止| J[单解或Pareto集]
```

- **直接决策机制：**编码、解码和可行化决定调度变量如何落地。
- **搜索效率机制：**自适应参数、PCA、种群合并、Q-learning选邻域等只改变搜索路径，不能单独视为问题创新。
- **失效边界：**编码未覆盖动态状态、路径或电池时，强化搜索并不能修复模型缺失。

## 4. 强化学习调度通用链

代表文献：B003、B004、B010、B012–B017、B020、B023、B027。

```mermaid
flowchart TD
    A[环境/图/局部状态] --> B[特征器: 手工特征/图网络/LSTM/视觉]
    B --> C[动作候选与可行掩码]
    C --> D{策略类型}
    D -->|值函数| E[Q-learning/DQN/DDQN/D3QN]
    D -->|策略梯度| F[PPO/A3C/MADDPG]
    E --> G[选直接决策或规则/邻域]
    F --> G
    G --> H[解码器或环境执行动作]
    H --> I[下一状态与奖励]
    I --> E
    I --> F
    H -->|终止| J[调度/路径/充电策略]
```

### 三种不同职责

1. **直接决策：**B004、B010、B012–B017、B020、B023直接输出调度、路径或充电动作。
2. **规则选择：**B027让D3QN选择复合派工规则，实际工序/机器动作由规则执行。
3. **搜索控制：**B001、B005的Q-learning选择邻域或搜索策略，主求解器仍是进化算法。

**失效边界：**训练分布偏移、不可观测状态、动作可行掩码遗漏、奖励错配或仿真—现实差距会导致策略失效。

## 5. 任务分配—路径规划混合链

代表文献：B007、B021、B024、B025。

```mermaid
flowchart TD
    A[任务/AGV/路网状态] --> B[任务与车辆分配]
    B --> C[A*或其他路径构造]
    C --> D[冲突检测]
    D -->|无冲突| E[可执行路径]
    D -->|有冲突| F{处理机制}
    F -->|局部约束| G[CBS/碰撞策略/时间窗]
    F -->|全局| H[重新规划]
    G --> D
    H --> B
    E --> I[执行并更新车辆状态]
```

- B007、B025更接近顺序/分层链；上游任务分配会限制下游路径空间。
- B021采用A*、DQN、CBS分层协作。
- B024在冲突时允许全局重规划，形成路径向任务层的反馈。
- **失效边界：**高密度冲突、频繁在线任务或通信延迟可能引发组合爆炸和过时计划。

## 6. 动态恢复通用链

代表文献：B001、B016、B027、B028、B029。

```mermaid
flowchart TD
    A[原计划执行] --> B{事件或决策点}
    B --> C[识别受影响资源/任务]
    C --> D[冻结已完成操作与继承状态]
    D --> E{恢复范围}
    E -->|右移/继续| F[保持机器和顺序, 调整时间]
    E -->|局部/部分| G[释放受影响变量]
    E -->|完全/全局| H[释放全部未完成变量]
    F --> I[可行性与稳定性评价]
    G --> J[规则/RL/进化算法重求]
    H --> J
    J --> I
    I --> K[新计划]
    K --> A
```

| 文献 | 事件入口 | 恢复范围控制 | 核心求解器 |
|---|---|---|---|
| B001 | 订单取消、机器/AGV故障 | 三类事件专用冻结与释放 | QNSGA-II |
| B016 | 新到达、工时不确定 | 右移与完全重调度组合选择 | 联合调度器＋时间窗路径器 |
| B027 | 完成点或新扰动 | 每个重调度点选择复合规则 | MachineRank＋D3QN |
| B028 | 机器/机器人故障、插单、充电维护 | 每次事件后全局连续重调度 | GA＋VNS |
| B029 | 机器故障 | 右移或完全重调度 | GA |

**共同缺口：**现有材料没有明确证明同一时段并发事件的联合状态继承与冲突解决。

## 7. 输出接口

| 输出 | 后续消费者 |
|---|---|
| 调度/路径/策略 | N6记录算例、指标和预算 |
| Pareto解集 | N6核验HV、IGD、C-metric等定义 |
| 恢复方案 | N6记录稳定性与动态协议；N7比较适用条件 |
| 机制失效条件 | N7局限评价；N8候选创新路线和失败出口 |
