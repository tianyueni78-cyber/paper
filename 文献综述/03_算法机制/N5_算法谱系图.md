# N5 算法谱系图

## 1. 谱系原则

本谱系按机制承担的职责分类，不按论文标题中的算法缩写分类。一个方法可同时属于多个分支，但每个分支必须说明它接收什么、计算什么、输出什么。

```text
调度求解体系
├─ P0 问题模型：定义实体、变量、约束、目标和事件状态
├─ P1 解/状态表示
│  ├─ 染色体：OS、MS、AS，或任务/路径多段编码
│  ├─ 图表示：析取图、异构图、拓扑/网格图
│  └─ RL状态—动作：资源状态特征、规则动作、直接联合动作
├─ P2 构造与初始化
│  ├─ 随机/规则/混合初始化
│  ├─ 混沌或多子群初始化
│  └─ 在线任务构造与优先规则
├─ P3 可行化与状态转移
│  ├─ 调度解码：机器—AGV时序、左移插入、充电检查
│  ├─ 路径器：A*、Dijkstra、时间窗
│  ├─ 冲突器：CBS、交通信号、碰撞/死锁处理
│  └─ 仿真/RL环境：状态更新、奖励和下一决策点
├─ P4 全局搜索或策略学习
│  ├─ 精确/下界：MILP、分支切割
│  ├─ 元启发式：GA、NSGA-II、DE、FPA、FOA、VNS
│  ├─ 值函数学习：Q-learning、DQN、DDQN、D3QN
│  ├─ 策略梯度：PPO、A3C、MADDPG
│  └─ 混合：全局搜索＋局部搜索/学习控制器
├─ P5 搜索强化机制
│  ├─ 交叉/变异、邻域、关键路径、接受准则
│  ├─ Q-learning选择算子/参数/规则
│  ├─ 注意力、LSTM、异构图特征融合
│  └─ 档案、非支配排序、拥挤距离
├─ P6 动态恢复
│  ├─ 事件检测与状态继承
│  ├─ 右移、局部修复、部分重调度
│  └─ 完全/全局重调度与连续重调度
└─ P7 输出
   ├─ 单一调度方案/路径/策略
   ├─ Pareto解集
   └─ 动态恢复方案及稳定性记录
```

## 2. 职责边界

| 组件 | 输入 | 核心职责 | 输出 | 不能替代 |
|---|---|---|---|---|
| 模型 | 实体、数据、假设 | 定义变量、约束、目标和事件 | 可求解问题 | 不等于求解算法 |
| 表示 | 问题状态或候选方案 | 将决策映射为染色体、图、状态/动作 | 可操作表示 | 不保证可行或优质 |
| 初始化/构造器 | 表示空间、规则 | 生成初始个体或在线候选任务 | 初始解/动作候选 | 不等于迭代优化 |
| 解码器/环境 | 染色体或动作 | 生成时序、资源状态和目标值 | 可行调度/下一状态 | 不等于优化器 |
| 优化器/策略 | 候选解、状态和反馈 | 搜索或学习选择决策 | 新候选解/策略 | 不自动处理未编码约束 |
| 路径器 | 起终点、路网、时窗 | 生成单车或多车路径 | 路径 | 不等于生产排程 |
| 冲突器/修复器 | 冲突或不可行方案 | 消除碰撞、死锁或约束违反 | 修复方案 | 不一定改善目标值 |
| 动态恢复器 | 事件、执行快照、原计划 | 冻结已完成状态并调整未完成部分 | 新计划 | 不等于事件检测器 |
| 仿真器 | 方案、环境规则 | 推进时间并生成反馈 | 轨迹/指标 | 不等于真实系统验证 |
| 评价器 | 解或轨迹 | 计算目标、指标和统计量 | 数值评价 | 不产生新方案 |

## 3. 四个方法家族

### 3.1 精确、规则与构造方法

| 机制 | 实际职责 | 文献映射 |
|---|---|---|

| 分支切割 | 强化 MILP 下界并求小规模基准 | B024 |

## 4. 动态恢复谱系

| 恢复机制 | 保留内容 | 可变内容 | 文献映射 |
|---|---|---|---|
| 事件专用部分重调度 | 已完成操作与事件前状态；按事件冻结部分变量 | 未完成工序顺序、部分机器/AGV选择 | B001 |
| 组合右移—完全重调度 | 右移时尽量保留原计划；完全重调度时释放更多变量 | 受影响任务或全部未完成任务 | B016 |
| 规则选择型动态调度 | 当前状态作为输入，学习器选择复合派工规则 | 下一工序/机器及后续状态 | B027 |
| 全局连续重调度 | 每次事件后以当前状态重新优化 | 未完成机器、机器人和运输序列 | B028 |
| 右移与完全重调度 | 原序延后或重新生成方案 | 机器故障周期后的任务 | B029 |

## 6. 同名与异名处理

1. `DQN`在 B015 可直接生成工件/车辆决策，在 B027 只选择复合调度规则；名称相同、职责不同。
2. `A*`在 B025 是排产后的路径器，在 B021 与 DQN、CBS构成分层链；不得合并成一个“改进A*机制”。
3. B001 与 B005 都使用 Q-learning，但前者选局部搜索邻域，后者控制果蝇搜索阶段；Q-learning不是主调度模型。
4. `联合/协同/集成`只描述问题耦合，不能说明算法内部是联合、分层还是顺序调用。
5. 算法组合符号“+”只表示组件并存；只有明确数据流后才能写成调用链。

## 7. 证据限制

- 本谱系回答机制职责，不评价谁的性能更好。
- B003、B012及部分网络首发文本对完整伪代码报告有限，相应调用细节保持概括。
- B016已由英文摘要和决策过程核实DQN、9种工序—机器—AGV复合规则及时间窗A*的职责；网络内部结构等转换缺失细节保持未报告。
- 具体预算、消融和统计有效性留到 N6–N7。
