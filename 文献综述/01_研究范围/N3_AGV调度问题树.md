# N3 AGV 智能调度问题树（候选）

## 1. 证据与用途

- 语料基线：29 篇可识别文献，其中 24 篇已有 Notion 字段级核验，1 篇 B001 为本项目动态机器—AGV联合调度研究对象，4 篇为补充背景文献。
- 本树回答“研究对象由哪些问题组成”，不评价具体算法优劣。
- 分类轴采用 N3 固定词汇：应用场景、决策对象、环境、扰动、方法族、评价目标；另记机器—AGV耦合方式。
- 证据编号沿用 `N2_书目核验表.md` 的 B001–B029；Notion 页序号沿用 N1 对照表。

## 2. 总问题

**在有限机器、AGV及路网资源下，如何联合决定加工、运输与恢复行为，使生产/物流系统在静态约束或动态扰动下保持可行，并在效率、稳定性、能耗、安全和计算成本之间取得可解释的权衡？**

这个总问题不能直接作为 RQ，因为它同时包含问题建模、机制选择和证据评价三个层次；N3 将其拆成三个可回答的问题。

## 3. 四层问题树

```text
AGV 智能调度
├─ A. 应用情境：决策发生在哪里？
│  ├─ 生产车间：JSP/FJSP、机器—AGV双资源、加工—运输—路径
│  ├─ 仓储系统：在线任务指派、多AGV路径、冲突/拥堵控制
│  ├─ 自动化码头：AGV—场桥、双循环运输、充电与路网
│  └─ 人机共融/通用调度：行人避让、分布式控制、领域综述
├─ B. 决策结构：系统必须决定什么？
│  ├─ 生产决策：工序顺序、加工路径、机器分配
│  ├─ 运输决策：任务分配、车辆选择、运输顺序
│  ├─ 移动决策：全局路径、局部避障、冲突/死锁消解、速度
│  ├─ 能源决策：充电时机、充电桩竞争、变速与电量均衡
│  └─ 恢复决策：继续执行、右移、局部修复、完全重调度
├─ C. 环境与扰动：为什么需要重新决策？
│  ├─ 静态确定：信息预先给定，无运行期事件
│  ├─ 动态确定：事件给定或由算例注入
│  ├─ 动态随机：到达、工时、故障或交通状态具有随机性
│  └─ 事件：新订单、订单取消、机器故障、AGV故障、工时变化、
│            充电维护、拥堵、动态障碍/行人
└─ D. 评价：什么证据可以支持“更好”？
   ├─ 效率：makespan、拖期、路径长度、等待时间、资源利用率
   ├─ 稳定/鲁棒：重调度偏差、延误率、动态适应性
   ├─ 能源：加工/运输能耗、电量均衡、充电桩利用率
   ├─ 安全：碰撞、死锁、避障/舒适成功率
   └─ 计算：运行时间、训练/求解预算、收敛与统计协议
```

## 6. 耦合方式（后续 N4/N5 的附加轴）

| 方式 | 操作定义 | 典型形式 |
|---|---|---|
| 联合 joint | 同一模型/染色体/策略同时决定机器与AGV相关变量 | 三层编码、多智能体联合动作 |
| 分层 hierarchical | 上层作任务/规则决策，下层作机器、车辆或路径决策 | 规则选择—资源分配；初始路径—局部修复—全局冲突 |
| 顺序 sequential | 前一子问题结果作为后一子问题固定输入 | 先任务分配，再路径规划 |
| 迭代 iterative | 多个子问题反复交换信息直至停止 | 生产计划与路径/冲突交替修正 |
| 未报告/不清楚 | 当前证据不足以判断 | 不按文件名或算法名猜测 |

## 7. 当前证据缺口

1. 订单取消的直接原始研究高度集中于 B001，不能据此声称已形成广泛共识。
2. 多数动态研究只处理单类或串行事件，并发事件边界证据不足。
3. 仓储路径研究与生产车间联合调度的模型边界不同，只能做机制迁移对照，不能直接比较性能数值。
4. 不同论文的预算、算例、指标和随机协议不一致；算法排名必须留到 N6–N7，在 N3 不作结论。

## 8. N3 分类轴建议

建议冻结六个主轴和一个附加轴：

1. 应用场景；
2. 决策对象；
3. 环境；
4. 扰动；
5. 方法族；
6. 评价目标；
7. 附加轴：机器—AGV—路径耦合方式。

这是问题驱动的最小轴集。暂不把“算法名称”设为分类主轴，因为算法名称不能解释其实际职责与调用链。
