# N3 术语表

## 1. 问题与资源

| 中文术语 | 英文/缩写 | 本项目操作定义 | 易混边界 |
|---|---|---|---|
| 自动导引车 | Automated Guided Vehicle, AGV | 在封闭生产/物流系统中承担物料运输，并受数量、位置、时间、路径或能量约束的移动资源 | 文献中的 transportation robot 若承担相同职责，可归入运输机器人，但保留原称 |
| 作业车间调度 | Job Shop Scheduling Problem, JSP | 每道工序的机器路线固定或基本固定的加工排序问题 | 不等同于机器可选的 FJSP |
| 柔性作业车间调度 | Flexible Job Shop Scheduling Problem, FJSP | 工序可在多个合格机器中选择，并同时确定机器分配和工序顺序 | 加入运输资源后须明确 FJSP-T/FJSP-AGV |
| 有限运输资源FJSP | FJSP with Transportation, FJSP-T | 在 FJSP 中显式建模有限车辆和运输时间 | 仅设置固定搬运时间但不分配车辆，不算完整联合调度 |
| 动态有限运输资源FJSP | DFJSP-T | FJSP-T 在运行中受订单、机器或AGV等事件影响并触发恢复 | “动态”必须有事件或在线信息变化，不能仅指随机初始化 |
| 双资源调度 | Dual-resource scheduling | 同时调度机器与AGV两类容量受限资源 | 若还显式优化路径，应写明机器—AGV—路径三层决策 |
| 多智能体路径规划 | Multi-Agent Path Finding, MAPF | 为多个AGV生成无时空冲突的路径 | 不等同于只分配运输任务 |

## 2. 环境与事件

| 中文术语 | 英文/缩写 | 本项目操作定义 | 易混边界 |
|---|---|---|---|
| 静态确定环境 | Static deterministic | 所有任务、资源和参数在调度前已知且运行期不变 | 多目标不意味着动态 |
| 静态随机环境 | Static stochastic | 调度前已知概率或不确定参数，但不发生在线事件更新 | 需与动态重调度区分 |
| 动态确定环境 | Dynamic deterministic | 运行期发生预设或确定注入的事件 | 固定故障时刻属于此类 |
| 动态随机环境 | Dynamic stochastic | 事件时刻、类型、持续时间或参数服从随机过程 | 只有多随机种子不等于事件随机 |
| 订单取消 | Order cancellation | 已进入计划的订单在运行期撤销，需要清理未执行加工和运输任务 | 不等同于新订单或工序报废 |
| 机器故障 | Machine breakdown/failure | 机器在故障区间不可用，并可能影响正在加工及后续工序 | 维护是否属于故障须按原文区分 |
| AGV故障 | AGV breakdown/failure | AGV在故障区间不可用，并影响负载、位置、电量与后续运输 | 路径堵塞不是车辆故障 |
| 新订单/插单 | New job arrival/order insertion | 运行期新增待加工或运输任务 | 与取消方向相反，不能合并为同一事件 |
| 加工时间变化 | Processing-time variation | 已知或执行中的加工时长发生变化或不确定 | 与机器停机时间分开 |
| 拥堵 | Congestion | 多车辆竞争路段/节点导致延迟或阻塞 | 碰撞是安全冲突，拥堵是流量/效率状态 |

## 3. 调度与恢复决策

| 中文术语 | 英文/缩写 | 本项目操作定义 | 易混边界 |
|---|---|---|---|
| 任务分配 | Task assignment | 将运输或加工任务分配给资源 | 不包含任务内部的路径细节 |
| 车辆分配 | Vehicle assignment | 为一次运输任务选择具体AGV | 与运输顺序分别记录 |
| 运输顺序 | Transportation sequence | 决定同一AGV执行多个运输任务的先后关系 | 不等于空间路径 |
| 路径规划 | Path planning | 决定AGV经过的节点/边及必要的时空占用 | 仅最短距离不保证无冲突 |
| 冲突消解 | Conflict resolution | 通过等待、优先级、改道、CBS等消除节点/边冲突 | 死锁检测属于相关但不同的可行性问题 |
| 重调度 | Rescheduling | 动态事件后重新生成或修改剩余计划 | 必须说明冻结部分和可变部分 |
| 右移重调度 | Right-shift rescheduling, RS | 保持资源分配和顺序，主要将受影响任务向后平移 | 不等同于重新优化 |
| 完全重调度 | Complete rescheduling, CS | 在保留已完成状态后，对未完成部分进行广泛重新优化 | “完全”不允许改写已完成历史 |
| 局部修复 | Local repair | 只调整受影响任务、资源或邻域 | 与元启发式局部搜索不是同一概念 |
| 继续执行 | Continue/initial schedule, IS | 事件后尽量继续原计划，仅接受由事件造成的推迟或不可用 | 具体定义遵循 B001 的实验策略 |
| 事件驱动 | Event-driven | 事件发生时触发调度更新 | 与固定周期滚动调度区分 |

## 4. 方法组件

| 中文术语 | 英文/缩写 | 本项目操作定义 | 易混边界 |
|---|---|---|---|
| 数学模型 | Mathematical model | 变量、目标和约束对问题的形式化表示 | 不等于求解算法 |
| 编码 | Encoding/representation | 将调度决策表示为染色体、动作或状态结构 | 不等于解码 |
| 解码器 | Decoder | 将编码映射为可执行时间表、资源状态和目标值 | 解码规则可实质改变模型行为 |
| 修复算子 | Repair operator | 把不可行或受事件影响的解恢复为可行解 | 不等于性能改进的局部搜索 |
| 优化器 | Optimizer | 搜索候选解的 GA、NSGA-II、FPA、VNS 等机制 | 使用算法名不自动构成创新 |
| 调度规则 | Dispatching rule | 根据当前状态直接选择任务或资源的启发式映射 | 可作为 RL 动作，但不等于 RL 本身 |
| 强化学习 | Reinforcement Learning, RL | 通过状态、动作、奖励和更新规则学习决策策略 | DQN、PPO等必须说明实际决策职责 |
| 混合方法 | Hybrid method | 两种以上机制在明确调用链中承担不同职责 | 简单并列算法名不构成机制说明 |
| 仿真器 | Simulator | 执行调度并产生时间、资源和事件轨迹的实验环境 | 仿真器不是优化器 |

## 5. 评价与证据

| 中文术语 | 英文/缩写 | 本项目操作定义 | 易混边界 |
|---|---|---|---|
| 最大完工时间 | Makespan | 最后一个纳入任务的完成时刻或总调度长度 | 动态场景须说明时间原点和已完成部分 |
| 总能耗 | Total Energy Consumption, TEC | 论文定义的机器、AGV、加工、空载/负载或充电能耗之和 | 不同能耗边界不能直接比较 |
| 重调度稳定性 | Rescheduling stability | 新旧计划在时间、顺序或资源分配上的偏离程度 | 不等同于随机算法方差 |
| 鲁棒性 | Robustness | 在扰动或参数变化下维持可行性/性能的能力 | 只在一个固定事件下有效不能泛化为鲁棒 |
| 直接证据 | Direct evidence | 原始论文实验、表格、公式或明确结论 | 综述转述属于二手主张 |
| 分析推断 | Analytical inference | 本研究基于证据提出的分类、迁移或实验建议 | 必须显式标记，不能写成作者结论 |
| DIRECT比较 | DIRECT | 关键问题和实验条件实质兼容的跨论文数值比较 | 需通过完整协议检查 |
| 论文内比较 | WITHIN-STUDY | 仅在同一论文共享协议下成立的相对结果 | 不外推为领域排名 |
| 定性比较 | QUALITATIVE | 条件不兼容时仅比较机制、方向和边界 | 不引用数值制造排名 |

## 6. 缩写使用规则

- 首次出现使用“中文全称（英文全称，缩写）”，后续使用统一缩写。
- `AGV` 可作单数或类别称谓；复数优先写“多AGV”，不强制使用 `AGVs`。
- `FJSP-T`、`FJSP-AGV` 若原论文定义不同，保留原术语并在首次出现时说明。
- L026 的正式方法记为“GA+VNS 模因算法”，禁止按文件名写成 `DDQN`。
- `A*` 统一写作 `A*`，不因 Markdown 转义写成 `A\*`。
