# N4 问题情境分类体系

## 1. 目的与版本

- 版本：`N4-TAX-v1.0`，日期：2026-09-01。
- 对象：N2 核验的 B001–B029，共 29 篇。
- 用途：回答 RQ1，描述“什么情境产生什么决策结构”；不在本节点评价算法优劣。
- 继承：沿用 `N3-RQ-v1.0` 的研究边界、六主轴及机器—AGV—路径耦合附加轴。

## 2. 证据与缺失值规则

1. 每篇文献保留一条主记录，多项并存时用“；”分隔，不复制成多篇。
2. `直接`表示可由摘要、模型、问题描述或方法章节定位；`间接`表示由全文结构综合判断；`待核`表示现有转换文本不足。
3. `未报告`表示论文没有给出该信息；`不清楚`表示现有材料存在歧义。二者均不得靠题名、算法缩写或常识补齐。
4. 综述文献使用`跨类型（综述）`，表示其总结多个类别，不代表作者建立并求解了一个混合情境模型。
5. 相邻场景和不含 AGV 的动态 FJSP 研究保留在矩阵中，但标记文献角色；它们只能支持机制或边界对照。

## 3. 分类轴

### 3.1 应用场景

| 值 | 操作定义 | 排除性说明 |
|---|---|---|
| 生产车间 | 加工机器、工序和车间运输至少两类对象参与决策 | 单纯仓储搬运不归入此类 |
| 仓储 | 货架、拣选台、库内任务或无人仓路网为主要对象 | 不因提到“智能物流”自动归入车间 |
| 自动化码头 | 岸桥/场桥、堆场和水平运输系统构成作业系统 | 只作异质资源协同对照 |
| 通用运输 | 未绑定上述具体行业的多 AGV 任务/路径系统 | 若场景未报告则同时标记未报告 |
| 人机共融 | 行人或人员安全空间直接进入决策或评价 | 普通静态障碍不构成人机共融 |
| 跨场景（综述） | 综述覆盖多个应用场景 | 不计作单一场景实验 |

### 3.2 资源系统

| 资源标签 | 含义 |
|---|---|
| 工件/任务 | 加工工件、搬运任务、订单或集装箱任务 |
| 机器/工位 | 加工机器、装卸/拣选工位或场桥 |
| AGV/机器人 | 有限车辆、运输机器人或异构 AGV |
| 路网 | 节点—边、网格、引导路径、交通信号或时间窗 |
| 能源设施 | 电池、充电站/充电桩、速度—能耗关系 |
| 人/动态障碍 | 行人或运行期障碍物 |

资源标签只说明进入问题的实体，不说明该实体一定是决策变量。

### 3.3 决策对象

| 值 | 操作定义 |
|---|---|
| 工序排序 | 决定工件/工序在资源上的加工先后 |
| 机器分配 | 为可选机器分配工序 |
| 车辆/任务分配 | 指定 AGV、运输机器人或车辆数量承担任务 |
| 运输排序 | 决定运输任务或车辆服务先后 |
| 路径规划 | 决定节点—边序列、时间窗或局部运动方向 |
| 冲突控制 | 对碰撞、死锁或拥堵进行预防/消解 |
| 速度决策 | 决定 AGV 速度档或连续速度 |
| 充电决策 | 决定充电时机、充电站或电量均衡行为 |
| 恢复决策 | 事件发生后选择继续、右移、局部修复或完全重调度 |
| 资源配置 | 决定 AGV 数量、类型或系统容量 |

### 3.4 环境：动态性与随机性

环境由两个字段组成，不能由算法类型推断。

| 字段 | 允许值 | 判定标准 |
|---|---|---|
| 动态性 | 静态；动态；跨类型（综述）；不清楚 | 运行期是否出现新信息、资源状态变化或重复在线决策 |
| 随机性 | 确定；随机；跨类型（综述）；未报告；不清楚 | 到达、工时、故障或运动是否由概率过程产生 |

- 固定时刻注入故障属于`动态＋确定`。
- 声称“实时/在线”但未说明概率模型时，动态性可判为动态，随机性记`未报告`或`不清楚`。
- 采用 DQN/PPO 不等于动态随机；使用遗传算法也不等于静态。

### 3.5 扰动与运行事件

| 组别 | 允许值 |
|---|---|
| 生产扰动 | 新订单/插单；订单取消；机器故障；AGV故障；加工时间变化 |
| 路网事件 | 拥堵；碰撞风险；死锁风险；动态障碍/行人 |
| 能源事件 | 低电量；充电维护/充电资源竞争 |
| 无事件 | 静态模型未设置运行期事件 |
| 综述/缺失 | 跨类型（综述）；未报告；不清楚 |

`多事件`表示一篇论文分别处理两种以上事件；只有论文明确允许同一时段重叠、联合触发或同时发生，才标记`并发事件`。连续发生但逐次处理属于`多事件非并发`。

### 3.6 关键约束

约束采用可复用标签：工序优先、机器可选/唯一占用、有限车辆、车辆容量、运输时间、车辆位置、路径互斥/无碰撞、死锁、时间窗、到达时间、故障不可用、状态继承、电池/充电、速度范围、异构车辆、顺序相关准备时间、人身安全距离。未在原文出现的约束不补写。

### 3.7 方法族与评价目标

为保持 N3 六主轴完整，N4 只做情境级预编码，详细机制和实验定义分别留给 N5、N6。

| 轴 | 允许值 |
|---|---|
| 方法族 | 精确；启发式；元启发式；学习型；混合；跨类型（综述）；未报告 |
| 评价目标 | 效率；稳定性；鲁棒性；能源；安全；计算成本；多目标组合；跨类型（综述）；未报告 |

### 3.8 耦合方式

| 值 | 操作定义 |
|---|---|
| 联合 | 同一模型、编码、状态—动作或解码过程同时决定两类以上相互制约的资源决策 |
| 分层 | 上层和下层承担不同决策职责，下层受上层输出约束 |
| 顺序 | 前一子问题求解完成后，其结果作为后一子问题的固定输入 |
| 迭代 | 子问题反复交换信息并相互修正直至停止 |
| 单层AGV | 只研究 AGV 任务、路径、避障或能源，没有机器调度耦合 |
| 单层机器 | 只研究加工调度/重调度，没有 AGV 决策 |
| 跨类型（综述） | 综述同时讨论多种耦合模式 |
| 未报告/不清楚 | 原文缺失或现有证据不能可靠区分 |

“集成”“协同”“联合”等题名用词不是`联合`的充分条件；必须看到共同模型、共同编码/动作或明确的信息交换链。

## 4. 文献角色

| 角色 | 使用方式 |
|---|---|
| 核心研究对象 | B001；直接服务三个 RQ，但不能单篇代表领域共识 |
| 核心车间原始研究 | 含机器与 AGV/运输资源的原始模型或实验 |
| 路径/任务相邻研究 | 仓储、码头、通用运输和人机共融研究；用于迁移和边界对照 |
| 动态机器相邻研究 | 不含 AGV 的动态 FJSP；仅支持恢复策略对照 |
| 综述 | 支持分类、术语和检索线索；不进入原始实验性能排名 |

## 5. 一致性检查示例

| 情况 | 正确编码 | 不允许的编码 |
|---|---|---|
| 固定时刻机器故障 | 动态＋确定；机器故障 | 因为“故障”直接写成随机 |
| PPO 求解固定码头算例 | 静态＋确定；学习型 | 因为使用 PPO 写成动态随机 |
| 在线周期批量任务到达 | 动态；新订单/任务到达；随机性按原文 | 只因“在线”认定随机 |
| 分别测试机器故障和 AGV 故障 | 多事件非并发 | 并发事件 |
| 先排产、再分车、再寻路 | 分层或顺序，并写明调用链 | 仅因题名写“集成”判为联合 |

## 6. N5/N6 交接边界

- N5 将复核方法族，并把“模型—编码/状态—解码/转移—修复—优化器”拆开。
- N6 将复核评价目标、指标定义、算例和预算。
- 因此本节点的方法族和评价目标只能用于覆盖描述，不支持算法排名或性能结论。
