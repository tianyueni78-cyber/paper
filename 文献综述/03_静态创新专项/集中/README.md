# 集中文献整合

## 目标

围绕当前静态机器–AGV论文完成P02创新性专项检索，不承担整个领域的算法百科整理。

## 六条检索线

1. 静态机器–AGV协同调度核心近邻；
2. Top-K、瓶颈和关键区域局部搜索；
3. 自适应邻域或算子选择；
4. 搜索预算、邻域强度和计算资源分配；
5. 强化学习超启发式；
6. 核心论文前向与后向引用追踪。

## 五类机制分类

- Top-K区域选择；
- 邻域选择；
- 预算或搜索强度选择；
- RL超启发式；
- 机器–AGV联合调度。

## 预定成果

- 检索日志与筛选流；
- 专项证据矩阵；
- 代表性和最新文献；
- 最近邻机制对比表；
- 本文机制差异；
- baseline覆盖性和选择理由；
- 创新性支持、反对和证据不足结论；
- P02十五项验收记录。

完整规则见[P02集中检索协议](P02_集中检索协议.md)。
