# 文献整合双轨结构

本目录同时服务论文的一般知识基础和当前静态创新判断，但两类证据不得混用。

## 泛式

整理语料中出现的全部问题、算法和方法，包括动态与静态研究。目标是回答“这个研究领域有哪些问题结构、算法族、关键模块、实验方法及适用边界”，不直接证明当前方法创新。

入口：[泛式整合说明](泛式/README.md)。

## 集中

只围绕当前静态机器–AGV论文，按六条检索线和五类机制分类寻找最近邻、比较机制并判断创新边界。

入口：[集中整合说明](集中/README.md)与[集中检索协议](集中/P02_集中检索协议.md)。

## 关系

```text
N1–N4既有资产与分类
        ↓
泛式：全领域算法/方法图谱（动态＋静态）
        ↓ 提供术语、方法族和候选近邻
集中：六条线专项检索＋五类机制对比
        ↓
P02十五项验收与当前论文创新边界
```

泛式中出现的论文只有满足集中检索协议的纳入与证据要求后，才能用于当前创新性结论。
