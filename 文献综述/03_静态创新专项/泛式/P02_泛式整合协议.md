# P02 泛式文献整合协议

## 1. 语料范围

- 起始语料：N1冻结的29篇文献及其N2书目证据；
- 后续语料：集中检索和引用追踪发现、经书目核验的相关研究；
- 时间与环境：动态和静态均纳入，确定性和随机性分别标记；
- 应用情境：车间为主，仓储、码头和运输研究在具有可迁移算法机制时纳入；
- 原始文献只读，所有分类和推断写入本目录的派生成果。

## 2. 分类轴

每篇论文至少按以下轴编码：

| 轴 | 必填内容 |
|---|---|
| 问题情境 | 应用场景、静态/动态、确定/随机、扰动 |
| 决策对象 | 工序顺序、机器、AGV、路径、速度、充电、恢复及组合 |
| 耦合方式 | 联合、迭代、分层、顺序、不清楚 |
| 模型与约束 | 目标、资源、运输、能源、故障和关键假设 |
| 算法族 | 精确、启发式、元启发式、学习、混合 |
| 算法组件 | 编码、初始化、解码、修复、全局搜索、局部搜索、学习控制 |
| 动态处理 | 事件、触发、状态继承、重调度策略 |
| 实验协议 | 实例、规模、对照、预算、重复、统计、指标 |
| 证据质量 | 证据类别、强度、可定位性、未决问题 |

缺失信息使用`未报告`，文本冲突或无法判定使用`不清楚`，不得凭算法名称补猜具体机制。

## 3. 整合方法

1. 继承N1–N4已有稳定文献ID，不重新编号；
2. 从原文抽取模型、算法组件和实验字段；
3. 区分数学模型、编码、解码、修复、优化器、仿真器和实验工具；
4. 先形成单篇证据记录，再按问题、算法族和模块综合；
5. 跨论文性能比较须通过六维可比性门；否则只作`WITHIN-STUDY`或`QUALITATIVE`比较；
6. 每项综合结论保留支持、反例、限制和未决证据。

## 4. 完成条件

- 所有纳入文献均有唯一记录；
- 动态与静态均有明确分类，不混写；
- 所有被论文正文使用的算法和方法均能追溯到原始证据；
- 没有把二手综述转述冒充原研究证据；
- 算法谱系、模块、实验条件和适用边界均形成可检查成果；
- 集中整合可从泛式台账筛选候选，但必须独立执行专项纳排和机制比较。
