# 泛式文献整合

## 目标

对`paper`仓库全部纳入文献及专项检索新增文献进行全景整理，覆盖动态与静态调度、全部算法族、方法模块、实验方法和适用边界。

## 必须覆盖的知识层

1. 问题层：静态/动态、确定/随机、车间/仓储/码头、扰动类型及机器–AGV耦合方式；
2. 模型层：决策变量、约束、目标、运输、路径、速度、充电、故障与恢复假设；
3. 表示与求解层：编码、初始化、解码、修复、选择、交叉、变异和局部搜索；
4. 算法族：精确算法、规则/启发式、进化算法、群智能、VNS/LNS/ALNS、超启发式、机器学习与强化学习、混合算法；
5. 动态机制：事件检测、重调度触发、IS/RS/CS或对应恢复策略、状态继承与可行性保持；
6. 实验层：数据集、规模、baseline、预算/停止条件、重复、随机种子、指标、统计和代码数据可用性；
7. 证据层：作者结论、直接证据、二手主张、分析推断、限制和未决事项分开。

## 边界

泛式允许纳入与当前静态论文不直接可比的研究，用于知识背景和方法谱系；不得据此进行跨论文性能排名，也不得因为某个机制在其他问题出现就直接判定当前组合不创新。
